# Lab 11 Implementation of memory managment in C++

# Task 1

A college maintains records of exactly 5 students for a small quiz test. The number of students is fixed. Task:
Design a program that:
Stores marks of 5 students using static array
Takes input from user
Displays all marks
Calculates total and average marks 
Constraints:
Use static memory allocation only
Array size must be fixed

# task 2

An online test system stores one student’s score dynamically because system does not know before execution which student will log in.
Write a program that:
Dynamically allocates memory for one integer score
Takes input from user at runtime
Displays score and memory address
Frees memory after use 
 Constraints:
Use new and delete
Use pointer

# task 3

An admission office does not know how many students will apply. The size is decided at runtime.
Develop a program that:
Asks user for number of students
Allocates dynamic array for marks
Takes input for all students
Displays all marks
Releases memory after processing 
Constraints:
Use new[] and delete[]

Write a program that:

Stores address in pointer
Displays:
Direct value
Address
Value using pointer 
Constraints:
Must use & and * operators
