# Lab 7 Implementation of Producer & consumer Problem C++

## task 1

Write a program that demonstrates how two processes can share a variable using semaphore.

## task 2

 A warehouse management system stores items in a limited-size buffer where suppliers continuously add products and customers remove them. Sometimes, the storage becomes full and suppliers must wait, while at other times it becomes empty and customers must wait. Explain how you would implement this system using the Producer–Consumer approach. Your answer should include how synchronization is maintained and how mutual exclusion is ensured.

## task 3

Consider a system where multiple threads are accessing a shared buffer simultaneously. One thread produces data and another consumes it. Without proper synchronization, the system may face data inconsistency and unexpected behavior. Describe the problems that may occur in such a system and explain how mutex locks and condition variables help in resolving these issues.
